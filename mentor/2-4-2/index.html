보고서 작성

EBS 튜터링 사이트 > 나의 활동 > 보고서 관리

  • 수업 종료 후 수업 접속 이력(LMS)이 연동되어, 2분 이내로 보고서 작성란이 생성됩니다.

※ 수업 종료 시, [수업 종료] 버튼을 클릭하여 수업을 종료해 주세요.

※ [수업 종료] 버튼을 클릭하지 않고 창을 닫은 경우, 재접속하여 다시 종료해 주세요.

※ 정상적으로 수업을 종료하지 않았을 경우, 보고서가 개설되지 않을 수 있습니다.

상단의 X 클릭 > 수업을 종료하고 모두 나가기 체크 > [나가기] 클릭

  • [보고서 관리] 페이지에서 [등록하기] 버튼을 클릭하여 보고서를 작성해주세요.

보고서 작성 가이드

멘티 출석

시작멘토 · 멘티 입장 후 함께 있는 화면 (멘티가 지각한 경우에는, ①멘토가 입장한 화면 + ②멘티 입장 이후 함께 있는 화면)
중간수업 자료를 띄운 채 수업 중인 화면
종료수업
종료직전, 멘토 · 멘티가 함께 있는 화면
수업 내용멘토 · 멘티가 모두 입장한 시간 기준으로, 수업 시작시간 ~ 종료시간 작성
  • 해당 튜터링 회차에서 진행한 수업 내용을 작성

예) 수업 시간 19:15 ~ 20:16 (61분) / 튜터링 3회차 / 뉴런 수학3 소단원 무리수와 실수 개념 설명 및 문제 풀이 (13~14p)

※ 모든 사진에 멘토·멘티의 얼굴, 날짜, 시간이 모두 나와야 합니다.

※ 멘티 지각의 경우, 시작 사진은 ①멘토 입장 화면과 ②멘티 입장 이후 함께 있는 화면의 합본을 제출해 주세요.

멘티 결석

시작멘토가 화상 수업 대기 중인 화면 (멘토의 입퇴장 시간을 확인할 수 있도록 얼굴, 날짜, 시간, 채팅창이 모두 보이게 캡처해주세요.)
중간멘토가 멘티에게 연락을 시도한 화면 (일시가 보이도록 캡쳐)
종료멘토가 멘티에게 과제물을 부여한 화면 (일시가 보이도록 캡쳐)
수업 내용멘토가 입장한 시간 기준으로 수업 시작시간 ~ 종료시간 작성
  • 멘티에게 과제물을 전달한 화면 스크린샷 첨부 (EBS 단추+ 활용하여 제작한 시험지 등의 과제물을 전달)

예) 대기 시간 19:15 ~ 19:30 (15분) / 튜터링 4회차 (멘티 무단결석) / 단추 시험지 – 소단원 무리수와 실수 (20 문항)

※ 멘티 무단 결석 시, 15분 대기해야 하며, 멘티에게 별도의 과제물을 부여해야 인정됩니다. (회차 인정, 준비 · 완료수당만 지급)

※ 멘티 인정 결석 시, 별도의 보고서를 작성하지 않습니다. 추후 멘티와의 협의 하에 수업 일정을 조율하여 진행하면 됩니다.

보고서 작성 유의사항

  • 클래스 1개당 보고서 1개씩 작성할 수 있습니다.

따라서 연강 진행 시, 회차별로 클래스를 별도로 개설해야 보고서를 각각 작성할 수 있습니다.

※ 클래스 별도 개설 없이 1개의 클래스에서 연강 진행 시, 1회차만 인정됩니다. (보고서 2개 작성 불가)

✅ 올바른 방법 10:00–11:00 (1회차) 클래스 1개 개설 + 보고서 1개 작성 11:00–12:00 (2회차) 클래스 1개 추가 개설 + 보고서 1개 작성 → 2회차 모두 회차 인정, 활동비 · 봉사시간 정상 지급

❌ 잘못된 방법 10:00–12:00 클래스 1개만 개설 해당 클래스에서 2시간 연속 수업 진행 (보고서 1개만 작성 가능) → 1회차만 인정, 활동비 · 봉사시간 1회차분만 지급

  • 근로장학생 멘토의 경우, 근로장학포털 출근부와 튜터링 보고서 모두 제출해야 합니다.
  • (출근부) 근로시간 인정기준 : 출근부에 제출한 멘토 · 멘티의 얼굴, 일자, 시간이 모두 보이는 사진을 기준으로 시작 시간과 종료 시간을 인정 (2026 대학생 청소년교육지원장학금 사업 업무처리기준안에 근거)

※ 멘티 무단 결석 시, 보고서는 반드시 제출해야 함. BUT 출근부는 제출 필요 없음. (제출 시, 삭제 처리됨)

  • (보고서) 수업시간 인정기준 : 튜터링클래스 LMS 기록 중 멘토와 멘티가 동시 접속해 있는 시간을 기준으로 시작 시간과 종료 시간을 인정 (보고서에 제출한 수업 증빙 사진 참고)
  • 기한 내 미 제출, 증빙자료 미흡으로 인해 인정되지 않은 보고서의 책임은 본인에게 있습니다.
